# OldSchoolDB Connector

A RuneLite plugin that syncs your bank, inventory, and equipment to [OldSchoolDB](https://oldschooldb.com) in real time — so you can track your items, prices, and account data from anywhere.

## Features

- **Bank Syncing** — automatically sync your bank items and quantities
- **Inventory Syncing** — track your inventory in real time
- **Equipment Syncing** — monitor your currently equipped gear
- **Price Tracking** — view current market values for all your items
- **Real-time Updates** — data syncs automatically whenever items change

## Setup

### 1. Create an account

Sign up at [oldschooldb.com](https://oldschooldb.com).

### 2. Get your plugin token

Go to **oldschooldb.com/plugin** → **RuneLite Plugin Token** → click **Generate Plugin Token** → copy it.

> **Note:** There are two token types on that page. The **RuneLite Plugin Token** goes in the plugin. **Developer API Keys** are for external tools — don't mix them up.

### 3. Configure the plugin

In RuneLite: open **Configuration** (wrench icon) → search **OldSchoolDB Connector** → set:

- **API Token** — paste your plugin token
- **Server URL** — `https://api.oldschooldb.com`
- **Welcome Greeting** — optional, customize your login message

### 4. Log in and verify

Log into RuneScape. The plugin syncs your bank, inventory, and equipment automatically. View your data at [oldschooldb.com](https://oldschooldb.com).
